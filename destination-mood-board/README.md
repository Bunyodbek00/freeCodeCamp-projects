# 🌍 Destination Mood Board

A fully interactive, responsive React web application that lets users explore, search, favorite, customize, and manage a dynamic mood board of dream travel destinations. Built with React, Vite, CSS Grid, and browser `localStorage`.

---

## ✨ Features

- **3D Card Flip Animation:** Click any card to smoothly flip it and reveal detailed information about the destination.
- **Live Search Bar:** Instantly filter destinations by title or description as you type.
- **Wishlist Counter & Bookmarking:** Save your favorite destinations with a heart toggle and track your count in real-time.
- **Custom Card Creator:** Add your own destinations with custom titles, image URLs, details, and card colors using a toggleable form.
- **Delete & Reset:** Remove individual cards or reset the entire board back to the default destinations.
- **"Surprise Me!" Randomizer:** Randomly picks, highlights, and flips a destination card for indecisive travelers.
- **Dark / Light Mode:** Seamlessly toggle between a warm cream theme and a sleek dark mode (with state persistence).
- **Persistent Storage:** All changes, custom cards, wishlist favorites, and theme choices are automatically saved to browser `localStorage`.

---

## 🛠️ Tech Stack

- **Framework:** React (Vite)
- **Styling:** CSS Grid & Flexbox, custom CSS 3D transforms
- **State Management:** React Hooks (`useState`, `useEffect`)
- **Data Persistence:** Browser `localStorage`

## 🚀 Getting Started Locally

Follow these steps to run the project locally on your machine:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Bunyodbek00/freeCodeCamp-projects.git
   cd destination-mood-board

2. **Install dependencies:**
    npm install

3. **Run the development server:**
    npm run dev

4. **Open your browser and navigate to the local URL provided by Vite (usually http://localhost:5173).
